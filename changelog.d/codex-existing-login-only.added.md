- `CODEX_REQUIRE_EXISTING_LOGIN=1` lets local `openai-codex` auth require an existing file-backed ChatGPT login on the first model call without starting device-code login or logging out through host login actions. Refusals identify the configured CLI and credential directory; after an external login, restart the host process (or its service), then retry, including when an existing session becomes unusable. Supplied `CodexAppServerAuth` instances inherit the policy; custom token callbacks own their internal auth policy. Existing-session refresh and default interactive login remain available. Refresh remains available until account or file inspection establishes that it is unavailable. Missing accounts and unusable files do not offer token refresh, and unrecognized flag values warn while retaining the off behavior.
