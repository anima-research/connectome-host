- `agent.cacheKeepalive.persist` (default `false`): saves the cache keepalive's state to `<dataDir>/cache-keepalive.json`, so after a restart the keepalive goes on refreshing the prompt cache when it's due, instead of nothing touching it until the next turn. Needs a membrane release with `cacheKeepalive.statePath`; with an older membrane the host warns at startup that the option does nothing.
