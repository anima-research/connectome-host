- `connectome service install <recipe>` writes and starts this install's resident service, a systemd user unit on Linux or a launch agent on macOS, and waits up to 60 s for its host to answer. The service's name comes from the name of the working directory that holds `.env`, in lower case, with each run of characters other than `a` to `z` and `0` to `9` made one `-` and none at either end: `~/.config/systemd/user/connectome-<name>.service` on Linux, and `~/Library/LaunchAgents/com.animalabs.connectome.<name>.plist` on macOS. A recipe whose text names `SESSION_SERVER_TOKEN` or `SESSION_SERVER_PORT`, or one of whose servers' command or arguments names the shell client, also gets a localhost shell daemon where `term-sessions-mcp` is installed, with its port and token kept in `.env`. The host's unit gets `CONNECTOME_SUPERVISED=1` only where its service manager restarts it on exit 75 and 1: on Linux once systemd shows it does, and on macOS always, since the agent's `KeepAlive` restarts it on any nonzero exit. The units run the `bun` on install's PATH when it is the Bun install runs on, as Homebrew's link is, which stays when `brew upgrade` removes the old version's file. Otherwise they run that Bun's own path.
