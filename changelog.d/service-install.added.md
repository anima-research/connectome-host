- `connectome service install <recipe>` writes and starts this install's resident service, a systemd user unit on Linux or a launch agent on macOS, and waits up to 60 s for its host to answer. The service's name comes from the name of the working directory that holds `.env`, in lower case, with each run of characters other than `a` to `z` and `0` to `9` made one `-` and none at either end: `~/.config/systemd/user/connectome-<name>.service` on Linux, and `~/Library/LaunchAgents/com.animalabs.connectome.<name>.plist` on macOS. A recipe whose text names `SESSION_SERVER_TOKEN` or `SESSION_SERVER_PORT`, or one of whose servers' command or arguments names the shell client, also gets a localhost shell daemon where `term-sessions-mcp` is installed, with its port and token kept in `.env`. The host's unit sets `CONNECTOME_SUPERVISED=1`, since it restarts the host on any nonzero exit: by `Restart=on-failure` on Linux, and by the agent's `KeepAlive` on macOS. The units run the `bun` on install's PATH when it is the Bun install runs on, as Homebrew's link is, which stays when `brew upgrade` removes the old version's file. Otherwise they run that Bun's own path. Under the systemd unit, the host's fleet children end when the host exits, by SIGKILL, a child it detached included. On macOS, the logs in the working directory's `logs/` grow until cut: stop the service, move the log, then start the service.
