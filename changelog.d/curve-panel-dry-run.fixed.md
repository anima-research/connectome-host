- The web console's context curve panel now compiles the resident's context as a dry run. A compile is only displayed, never sent, so it no longer commits fold resolutions or queues compression work each time the panel renders, mid-stream included. With context-manager's thinking binding, a committed compile that's never sent would also fence the replies the resident is streaming. When the context's plan is over budget, the panel now plots where it used to fail, since a dry run reports an over-budget plan instead of throwing. A later stage that can't fit still fails, as before.
