- The web console's context curve panel now compiles the resident's context as a dry run. A compile is only displayed, never sent, so it no longer commits fold resolutions or queues compression work each time the panel renders, mid-stream included. With context-manager's thinking binding, a committed compile that's never sent would also fence the replies the resident is streaming. At a budget too small for the context, the panel now plots, where it used to fail, since a dry run reports being over budget instead of throwing.
