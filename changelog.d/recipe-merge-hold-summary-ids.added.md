- `agent.strategy.mergeHoldSummaryIds` is passed through to the context manager (operator merge holds; context-manager #117) for the built-in strategies; a custom strategy type receives the list in its config. A malformed value (not an array of non-empty ids, or an id with spaces around it) now fails at recipe load instead of being silently dropped. At start, a `[merge holds]` warning names each held id the agent's store has no summary for, and each one already merged, which a hold doesn't undo. The ids name summaries in the store of the session the host runs, a session switch included, and the warning runs again on a switch. A subconscious fork (reader "forks") keeps the holds, since it shares the agent's summaries; a conversation fork, whose summaries have ids of their own, isn't held.
