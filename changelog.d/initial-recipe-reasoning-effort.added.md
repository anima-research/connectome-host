Recipes can set `agent.thinking.effort` before the first Anthropic streaming request, for example `"thinking": { "enabled": false, "effort": "medium" }`. The recipe remains the effort baseline across unrelated settings updates and restarts. Explicit agent effort overrides it until reset, including an explicit `"default"`; legacy saved `"default"` is treated as unset. Other providers ignore this field; OpenAI recipes use `agent.responses.reasoningEffort`. Compression calls are unaffected.
