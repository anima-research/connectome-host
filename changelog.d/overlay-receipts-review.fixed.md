- `mcpl_restart` keeps its overlay note when the restart throws, and an `mcpl-servers.agent.json` that can't be read no longer turns a successful restart into "mcpl_restart failed": the receipt reports the restart and says the file couldn't be read, without quoting it. The overlay-replacement receipts no longer report `AGENT_TIMEZONE`, which the host sets over every server's mapping, as lacking, and they do report a replacement that names a different `access` grant as lacking the operator's. An entry with a malformed `access`, `args` or `env` reads as lacking, or as having no references. A hand-edited `access` grant name is read trimmed, as `mcpl_deploy` writes it, so the host asks for the grant the receipts compare. A hand-edited entry that names both a `command` and a `url` is read by the connection agent-framework opens for it, which an explicit `transport` decides.
