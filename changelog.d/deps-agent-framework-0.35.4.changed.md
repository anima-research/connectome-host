- **agent-framework ^0.35.4** (the lockfile from 0.35.3). This release's range starts here: the `workspace.outsideMounts` entry below names 0.35.3 as the start it needed, and this one raises it. What a host gets: a send that fails beside `skip_reply` in the same step now reaches the model in that turn — `skip_reply` is refused naming the failed tool and the model is called again — where before the turn ended and nothing said the message wasn't posted (0.35.4); an emoji in a reply-judge rule no longer makes the judge's request fail with HTTP 400 and wake the agent on every refused batch (0.35.3); a held draft left alone for a whole turn is set aside when that turn ends (0.35.4, Changed); a resident is told when an MCPL server holds no grant, in a `[no-grant]` notice (0.35.4). A 0.27.1 host reproduced the first: `channel_publish` to an id no channel has, with `skip_reply` in the same step, ended the turn with the error in the step's results, no model call after it and no line in the host's log; the resident reported the failure only when asked four minutes later.
