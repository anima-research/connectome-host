- `modules.workspace.outsideMounts` lets the workspace's `read` and `read_image` take an absolute path, or one that starts with `~/`, for a file outside every mount (`"read-only"`), and `write` too (`"read-write"`). Left out, every path is a mount's, as before. Such a file is read and written as the host's own user, through no mount's boundary, and nothing of it is stored; an absolute path that lies in a mount is that mount's file. The tools' descriptions say what the setting allows, so setting it changes them. Needs the agent-framework release that carries `WorkspaceConfig.outsideMounts`.
