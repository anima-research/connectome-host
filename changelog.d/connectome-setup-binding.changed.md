- An install's record now holds the directory its root is in (`workingDir`), and `start.js` and the install's `connectome` command, before they load any release, refuse to run an install moved or copied away from it, naming setup. Setup run in the new directory binds the install there: each place under the old directory becomes the same place under the new one, in the record, in the copy labels and in each Go back's list of places, and setup asks where each place outside the old directory is now, or takes it by hand as `--place PATH PLACE`. A binding that changes a path in a copy label or a Go back's list writes its plan first, and if it's cut off, nothing starts there until the next setup finishes it from the plan, without asking again, or says what stops it, as when the install was moved again meanwhile. A Go back to a release from before this one keeps that refusal only until that release's own setup runs there, since that setup writes `start.js`, and `connectome` where it has one, without it, and the record without `workingDir`. An install set up before this release has no `workingDir`, so it's checked for a move or a copy only after setup next runs there, which takes each place under the directory that holds the install root as this install's, unless another install's root lies between, and asks about each other place. Once this release's setup has written the install's command, its `connectome setup` runs the setup of the package installed in its directory when the release it runs has none.
