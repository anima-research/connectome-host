- **Recipe authors:** with the context-manager release that brings `imageCeiling` and `imageByteCeiling`, a `maxLiveImages` or `maxLiveImageBytes` of 0 under `agent.strategy`, which turned that limit off, now means up to its ceiling: 500 images, or 24 MiB of base64, by default. A value above its ceiling, such as a `maxLiveImageBytes` of 30 MiB, is held to the ceiling, and the strategy warns about it when it starts. An agent whose recipe set either keeps the ceiling's worth, and its strategy logs a line naming the ceiling, the first time after it starts that the ceiling decides that an image is shown as a placeholder.
  - **Migration:** to keep no limit, or a limit above a ceiling, set that ceiling to 0 or raise it. An install that raised `MEMBRANE_MAX_REQUEST_BYTES` raises `imageByteCeiling` with it.
  - **Unchanged:** a recipe that sets none of these keeps 6 images and 20 MiB, under the default ceilings, and an `imageStripDepthTokens` of 0 still turns the depth limit off.
