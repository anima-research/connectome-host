- **Recipe authors:** with the context-manager release that brings `imageCeiling` and `imageByteCeiling`, a `maxLiveImages` or `maxLiveImageBytes` of 0 under `agent.strategy`, which turned that limit off, now means up to its ceiling: 500 images, or 24 MiB of base64, by default. An agent whose recipe set 0 to keep every image keeps the ceiling's worth, and its strategy says once in the log, the first time a ceiling decides that an image is shown as a placeholder, which ceiling it was.
  - **Migration:** to keep no limit, set `imageCeiling` and `imageByteCeiling` to 0 as well. An install that raised `MEMBRANE_MAX_REQUEST_BYTES` raises `imageByteCeiling` with it.
  - **Unchanged:** a recipe that sets none of these keeps 6 images and 20 MiB, under the default ceilings, and an `imageStripDepthTokens` of 0 still turns the depth limit off.
