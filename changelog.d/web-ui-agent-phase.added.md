- The web UI server reports each agent's phase to clients holding `health`: the tree's own words (`sending`, `streaming`, `invoking`, `executing`, …) and when it began, with no content. It arrives as a new `agent-phase` frame, in the welcome's `agentPhases`, and in `/healthz`'s `agentPhases`, so a dashboard can show what an agent is doing without being granted its messages. `/healthz` also keeps `kind` in `agents[].upcomingWakes` for clients without `ops`.
