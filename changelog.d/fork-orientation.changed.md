- A fork or spawn that waits for a subagent slot is now created with what was resolved at its call, which is what its receipt describes. Before, it read the caller's settings again when a slot freed: the system prompt (for a fork that names none), the prose routing, and the output limit when the call gives none and no subagent default is configured. A fork or spawn whose caller was gone by then got the framework's default prose routing and, when neither the call nor a subagent default sets one, a 4,096-token output limit; a fork that names no prompt also got the research-assistant prompt. Each now keeps its caller's values from the call.
