- A fork or spawn that waits for a subagent slot is now created with what was resolved at its call, which is what its receipt describes. Before, it read the caller's settings again when a slot freed: the system prompt (for a fork), the prose routing, and the output limit when the call gives none and no subagent default is configured. A fork whose parent stream was gone by then got the research-assistant prompt, the framework's default prose routing and, with no default configured, a 4,096-token output limit. It now keeps the parent's values from the call.
