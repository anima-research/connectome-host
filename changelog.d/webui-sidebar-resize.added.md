- The Web UI's right sidebar can be resized and hidden. Drag its left edge
  (or focus the edge and use the arrow keys) to change its width, and
  double-click the edge to go back to the default; `»` at the end of its
  tabs hides it to a narrow strip, and `«` there shows it again. The browser
  remembers both in `localStorage`. Below 768 px, a browser with no saved
  choice starts with it hidden, so the chat has the screen on a phone. Its
  tabs scroll sideways when the sidebar is too narrow to show them all.
