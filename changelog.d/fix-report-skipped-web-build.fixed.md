- A failed optional Web UI build no longer vanishes. `postinstall` used to end with `|| true`, so a failing `npm --prefix web install` or `run build` left no trace and the Web UI quietly answered 503. The install still succeeds (exit 0), but the script now reports the failure on stderr, naming the retry command (`npm run build:web`). Without a `web/` directory it stays silent, and a working build prints nothing extra.
- The host also says once at start, on stderr, when an enabled Web UI finds no bundle at its resolved path. That covers a build that was skipped rather than failed (for example `--ignore-scripts`). The page keeps its 503 and its remedy.
