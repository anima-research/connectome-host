- `fleet--peek` returns a child's events without a failure's own text: each event's `error`, `stack` and `providerErrorCode`, an `ops:alert`'s `message` and `data`, and an `errorType` of `safety`. These fields can carry a provider's error text or a refusal's category, and a parent agent read them there. Everything else in each event stays, such as its type and time, `errorType`, `httpStatus`, `retryable`, `shownReason`, speech and tool calls, and the child's event buffer keeps each event whole. A parent no longer reads the text of a child's failed tool call in `fleet--peek`, only that it failed.
