- An update's install with Bun first sets the new release's `package.json` `trustedDependencies` to exactly the packages whose install scripts the running Bun runs by default (`bun pm default-trusted`) and term-sessions-mcp, the list setup writes, so an update through a mirror or company registry runs the install scripts an update from npm runs, and a name a later Bun adds to that list reaches existing installs. When Bun can't give the list whole, the install keeps the running release's field, or none where it has none, and the update says so. An install with npm is as before.
