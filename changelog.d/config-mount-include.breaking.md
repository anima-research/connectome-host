- **Operators with `configMount`:** the `_config` mount now versions only files named `gate.json` or `gate.js` in the session's config directory (connectome-host#278). Every other file there, such as an Emacs autosave (`#gate.json#`) or a copy kept beside the config, is no longer versioned, or written back after an undo, a redo or a branch switch. Such files stay on disk as they are, and history from before is left as it was. Vim's `.swp` and `.swx` files and `~` backups were already passed over, and a restored file kept its mode, since agent-framework 0.22.3, first in connectome-host 0.11.0. A file you keep there and want versioned belongs in a mount of its own.
- **Agents:** a write to any other path under `_config/` is refused as outside the mount's include, and `saveAs` refuses `_config`. Write the gate's files with the gate's tools, as before.
- **Recipes whose only writable mount is `_config`:** agent-framework kept spilled tool results and fetched references there (`tool-results/`, `refs/`). It now keeps none in a file, since it keeps them only in a writable mount without an include, and a note from before that points at one is refused. The files stay on disk under the session's `config/`. A writable mount of the recipe's own keeps them.
- **`/files` clients:** a file under `_config/` other than those is answered `403`, where it was served.
