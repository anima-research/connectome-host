- `mcpl_deploy` dials a service by the name of its access grant: with `access` and no `url` or `command`, the host reads the home node's directory afresh (`GET /services` → `mcpl`, wss only) and dials the endpoint it publishes for that audience, so a resident who is their own operator is never handed an address, or asked to judge whether the network to it is private. The url found is saved with the entry, and the deploy's receipt names it, whether the dial succeeds or fails. When the directory publishes no endpoint for the audience, the refusal names the audiences it publishes one for; when the directory can't be read, the refusal says so. A cleartext refusal of an `access` deploy names the endpoint the directory publishes for that access, where it publishes one, and says to leave `url` out.
