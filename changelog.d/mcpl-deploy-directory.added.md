- `mcpl_deploy` dials a service by the name of its access grant: with `access` and no `url` or `command`, the host resolves the url from the MCPL endpoint the home node publishes for that audience (`GET /services` → `mcpl`, wss only), so a resident who is their own operator is never handed an address, or asked to judge whether the network to it is private. The url found is saved with the entry, and the receipt names it. Recipe `identity.mcpl` (audience → url) overrides the directory, as `identity.services` does for HTTP bases. A cleartext refusal of an `access` deploy now says to leave `url` out.
